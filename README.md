# corner-scouting

https://drive.google.com/drive/folders/1VqjDC-j2P2vSXZmH6q83Rtac_39KSRYG?usp=drive_link
Analyzing team corner-kick tendencies and outcomes using StatsBomb open data. This project produces reproducible analyses and per-team scouting dossiers focused on corner-kick tendencies, outcomes, and recommendations.

Planned outputs

- Corner table (aggregated corner events and outcomes per team)
- Team statistics (corner creation, success rates, shot generation from corners)
- Static setup groups (common player/ball placements and roles on corners)
- Scouting dossier (team-by-team PDF or notebook summarizing tendencies and recommendations)
